# The Scriptorium – Book Video Library

A medieval-themed website where people can add and watch videos about books.

## Features
- Add a video with title, book name, author, shelf, YouTube link and description
- Watch YouTube videos on the page
- "Find video" button for entries without a link
- Search by title, book or author
- Filter by shelf (History, Romance & Legends, Philosophy, Poetry, Science, Other)
- Remove videos
- Medieval look with blackletter fonts, parchment and gold borders
- Saves the library in the browser

## How to run
Open index.html in any browser.

## Tech
HTML, CSS, JavaScript (no frameworks)

## Note
Videos are saved only in each visitor's own browser. To share one library with all visitors, connect a database such as Firebase or Supabase.
